# smachine

## / Overview

ブラックボックスフィルタを回避して`0x1337`を作る

## / Writeup

`add`,`sub`,`mul`,`or`,`and`,`win`,`regs`が指定できる仮想マシンに接続出来ます。

`regs`はレジスタの現在の値を表示できて、初期状態では全て0です。

```
 #> regs
x0 = 0x0000
x1 = 0x0000
x2 = 0x0000
x3 = 0x0000
x4 = 0x0000
x5 = 0x0000
x6 = 0x0000
x7 = 0x0000
x8 = 0x0000
x9 = 0x0000 
```

`add`から`and`は第１引数にレジスタ、第２引数にレジスタか数字を指定することで計算できます。

```
 #> add x0 56
```

`win`を呼び出した時にいずれかのレジスタの値が`0x1337`であればフラグが表示されます。

試しに以下の手順で`x1`に`0x1337`を作ろうとしたらフィルターに引っかかりました。

```
#> add x1 255
#> add x2 19
#> mul x1 x2
#> add x1 74
Bad Result
```

そこで、一旦`x1`を`0x1336`にしてから下一桁をビットフリップすることで`ox1337`にしたらフィルターを回避してフラグが取れました。

```
#> add x1 255
#> add x2 19
#> mul x1 x2
#> add x1 73
#> or x1 1
#> win
```

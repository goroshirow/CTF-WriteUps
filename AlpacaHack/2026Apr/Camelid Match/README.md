# Camelid Match

## / Overview

`♧`の間隔に注目

## / Writeup


0,1を取る数のペア(a, b)が(1, 1)である時に`y`を，それ以外の時に`n`を10回連続で正解できれば成功です．ただし，(a, b)は次の様に暗号化されています．

- `enc`関数で1を`♡♧`, 0を`♧♡`に変換します．
- `row`関数で enc(1-a) + ♡ + enc(b) を計算します.
- `rot`関数で文字列をランダムな数だけビットローテーションします．

rot関数の直前までを具体例で見ましょう．

- (1, 1)の時

enc(1-1) + ♡ + enc(0) = `♧♡♡♡♧`

- (1, 0)の時

enc(1-1) + ♡ + enc(0) = `♧♡♡♧♡`

- (0, 1)の時

enc(1-0) + ♡ + enc(1) = `♡♧♡♡♧`

- (0, 0)の時

enc(1-0) + ♡ + enc(0)= `♡♧♡♧♡`

この後に`rot`関数に通すとランダムな数だけローテーションしますが，`y`と`n`を判別する普遍的な法則が一つだけあります．それが`♧`の間隔です．(1, 1)の場合は`♧`の間隔が常に0 (もしくは3) であり， `n` の場合はそうではないことが分かります．

よって，暗号文の`♧`の間隔が0の時に`y`を，それ以外の場合に`n`を送ればフラグが得られます．

### 別解

別解と言うほどでもないですが，`n`の生起確率が3/4であることを用います．(全体の4通りの内，`y`は(1, 1)の時しか生起しないため)

10回連続で`n`である確率は (3/4)^10 ≒ 0.0563135147 なので5.6%くらいです．何度もチャレンジして`n`を送信し続ければ現実的な回数でフラグが得られます．

# fake-shuffle-proof

## / Overview

異なるペアのハッシュを転用

## / Writeup

トランプのカード`A♠`, `A♥`, `K♠`, `K♥`が用意されます．またそれぞれのカードは0,1,2,3の数字が割り当てられています．

スクリプトを実行すると3つのモードを選ぶことができます．

`1) issue`を選択すると，**2つの違う色のカードを使ったハッシュ値**が得られます．別の言い方をすると，(`A♠`, `K♥`)か(`A♥`, `K♠`)のカードペアのハッシュ値を得ることができます．

`2) verify`では，2つのカードを選択し，それらのハッシュ値を予想します．

`3) exit`はプログラムを終了します．

目標は`2) verify`で**2つの同じ色のカードを使ったハッシュ値を当てる**ことです．ただし，同じカードは選択できないので，(`A♠`, `K♠`)か(`A♥`, `K♥`)のペアのハッシュ値が知りたいです．

攻略のカギはハッシュを生成する関数の中にあります．

```py
def rank_only_commit(a, b):
    ra = a // 2
    rb = b // 2
    x, y = sorted([ra, rb])
    return hashlib.sha256(f"{x}|{y}|{KEY}".encode()).hexdigest()
```

今までの議論を割り当てられた数字に置き換えると，(0,2), (1,3)のハッシュを知ることができて，(0,4), (1,2)どちらかのハッシュを当てなければならないのですが，関数を見るとハッシュ生成に使う数字は割り算の切り捨てを行っているので0と1は同じ扱いになります．つまり(0,2)と(1,2)は同じハッシュ値になるということです．なので`1) issue`で(0,2)のハッシュを知り，`2) verify`で(1,2)を選択して同じハッシュ値を入力すればクリアです．

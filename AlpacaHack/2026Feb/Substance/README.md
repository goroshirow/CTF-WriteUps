# Substance

## / Overview

最大公約数と下位8ビット条件

## / Writeup

2から2026までの乱数`r`を用いて
`flag*r1*r2*r3`と`flag*r4*r5*r6`が与えられます。

まずは2つの数の最大公約数(GCD)をとると、`flag*GCD(r1*r2*r3, r4*r5*r6)`が得られます。

`GCD(r1*r2*r3, r4*r5*r6)`を除去するために下位8ビットを見ます。なぜなら最後は必ず`}`=`0x7d`で終わるからです。とりあえず偶数ではないので2で割ると次の数が得られます。

```
3^4 · 269 · 503821 · 4572850661 · 3162243622...01
```

2026未満の数字は 3, 269 だけなので、9通りの割り算を試せば答えが求まります。この時 128 で割った余りが 0x7d=125 であればそれが答えです。

# missing ✌️

## / Overview

未知の係数$`c_0, c_1, c_2, P`$に対して以下の式が与えられます。

$$f(x) = c_0 + c_1 x + c_2 x^2 \pmod{P}$$

$`f(1)`$から$`f(10)`$までの10個の値がわかっている時、未知係数を求められるでしょうか？

## / Writeup

仮に$`P`$が求まったとします。この時、6/22のDaily AlpacaHackの問題[✌️✌️✌️](https://alpacahack.com/daily/challenges/3-pieces)と同じ方法で解くことができます。

そのため今回の方針は$`P`$を求めることです。

有限体の法を求める問題として頻繁に登場するのが、同じ代表元で表される2つの数を作り出すことです。例えば$`m_1 \equiv m_2 \pmod{P}`$かつ$`m_1 \ne m_2`$となる2整数を作り出せたとします。この時$`P | (m_1 - m_2)`$であるので、$`(m_1 - m_2)`$の素因数分解に$`P`$が登場します。

問題に戻ると、今10本の方程式が与えられている状況です。多項式の次数は2次ですから、4本の方程式を持ってくれば必ず線形従属な関係を作ることができます。

$$\sum_{i=1}^{4}a_if(i)=0 \pmod{P}$$

具体的な係数 $`a_i`$ を求めるため、多項式の値の数列に対して階差をとると次数が下がるという性質を利用します。隣り合う2つの多項式の差分がどうなるか考えます。

$$D(i) = f(i+1) - f(i) = c_1 +  c_2 (2i+1) \pmod{P}$$

さらに差分の差分は

$$DD(i) = D(i+1) - D(i) = 2 c_2 \pmod{P}$$

さらに差分の差分の差分を考えると

$$DD(i+1) - DD(i) = 0 \pmod{P}$$

です。これを$`f(i)`$を使って展開すると

$$
\begin{align*}
    DD(i+1) - DD(i) &= D(i+2) - D(i+1) - D(i+1) + D(i) \\
                    &= f(i+3) - f(i+2) -2(f(i+2) - f(i+1)) + f(i+1) - f(i) \\
                    &= f(i+3) - 3f(i+2) + 3f(i+1) - f(i) \\
                    &= 0 \pmod{P}
\end{align*}
$$

です。

よって$`f(i+3) + 3f(i+1) \equiv 3f(i+2) + f(i) \pmod{P}`$が常に成り立ちます。例えば$`i=1`$を選ぶことで、$`P`$を素因数にもつ$`N = [f(4) + 3f(2)] - [3f(3) + f(1)]`$を作り出すことが可能です。

あとはこの$`N`$を素因数分解して$`P`$を求めることが出来るので、これを用いて$`f(1)`$から$`f(3)`$の連立方程式から$`c_0, c_1, c_2`$を求めることもできます。

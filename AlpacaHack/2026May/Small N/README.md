# Small N

## / Overview

RSAの法を素因数分解

## / Writeup

今回の問題はオーソドックスなRSA暗号に関する問題です．

RSA暗号は $`N=pq`$ から$`p, q`$ を素因数分解することが困難であるという問題に基づいた暗号ですが，今回のチャレンジでは $`q`$ が明らかに小さいです．そのため総当りするか，もしくは[factordb](https://factordb.com/index.php)という素因数分解のデータベースを使えば簡単に素因数分解ができます．

秘密鍵は$`d=e^{-1} \pmod{(p-1)(q-1)}`$ で求められるのでフラグが復号できます．

q = 2563568311
p = n // q

phi = (p-1)*(q-1)
d = inverse(e, phi)
m = pow(c, d, n)
print(long_to_bytes(m))

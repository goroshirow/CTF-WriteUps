# Linear Coffee Generator

## / Overbview

線形合同法 (Linear congruential generators, LCG) のパラメータを4つの出力から求める。

## / writeup

LCGは疑似乱数を生成する方法の一つで初期値 $`s_0`$ に対して次の漸化式を適用することで乱数を生成します。

$s_{i+1} = as_i + b \bmod p$

問題では、4ラウンド分の出力が公開情報として与えられており、ここからパラメータ $`s_0`$, a, b, p を求めることがゴールです。

4ラウンド分の出力とはつまり:

* $`s_1 = as_0+b \bmod p`$
* $`s_2 = a^2 s_0+(a+1)b \bmod p`$
* $`s_3 = a^3 s_0+(a^2 + a + 1)b \bmod p`$
* $`s_4 = a^4 s_0+(a^3 + a^2 + a + 1)b \bmod p`$

のことです。

### pの導出

まず、 $`d_i = s_{i+1}-s_i`$ を定義します。

* $`d_1 = a\{(a-1)s_0 + b\} \bmod p`$
* $`d_2 = a^2\{(a-1)s_0 + b\} \bmod p`$
* $`d_3 = a^3\{(a-1)s_0 + b\} \bmod p`$

ここで $`d_1 d_3 \equiv {d_2}^2 \bmod p`$ なので、$`|d_1 d_3 - {d_2}^2|`$ は p の倍数になります。つまり、$`|d_1 d_3 - {d_2}^2|`$ を素因数することで p の候補を絞ることができます。

実際に[factor.db](https://factordb.com/index.php?query=18015186145068426177274734295463492132)で解くと

$`|d_1 d_3 - {d_2}^2|= 2^2 · 9197623 · 37447334611 · 13076220846716751461`$ 

になりますが、$`p>s_i`$ なので 

$`p=13076220846716751461`$ 

ということになります。

### aの導出

次に、p が求まったことで法 p の逆元を求めることができるようになりました。$`{d_1}^{-1} \bmod p`$ （拡張ユークリッドの互除法などで求める）を使うことで a が求まります。

$`{d_1}^{-1}d_2\equiv \frac{a^2\{(a-1)s_0 + b\}}{a\{(a-1)s_0 + b\}}\equiv a \bmod p \\ = 6534081916410610007`$

### bの導出

b はこれまでに求めた a, p を使って: 

$`s_2 - as_1 \equiv (as_1 + b) - as_1 \equiv b \bmod p \\ =12854780772490122855`$

と求めることが出来ます。

### $`s_0`$の導出

最後に a の逆元 $`a^{-1} \bmod p`$ を使って

$`(s_1-b)\cdot a^{-1} \equiv s_0 \bmod p`$

で $`s_0=12938961673315310206`$ が求まります。

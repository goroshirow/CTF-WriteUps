# Small e

## / Overview

公開鍵が小さいRSA

## / Writeup

RSAの暗号文は $`c = m^e \pmod{n}`$ で表されますが、もし $`m^e < n`$ であれば剰余を無視して $`m^e \pmod{n} = m^e`$ となります。すなわち $`\sqrt[e]{c} = m`$ が計算できます。

今回のチャレンジでは`assert len(FLAG) < 50`という条件より $`m < 2^{8\cdot49} = 2^{392}`$ であることが分かります。これを $`e=5`$乗 しても $`c < 2^{1960}`$ であり、$`2^{1024}2^{1024} < pq = n`$ との間に

$$c < 2^{1960} < 2^{2048} < n$$

という関係が成り立ちます。そのため今回の議論を適用することが可能です。

pythonで実装する際は精度を保つために`gmpy`の`iroot`を使って実装します。

## / Solver

```py
n = ...省略...
e = ...省略...
c = ...省略...

import gmpy2
from Crypto.Util.number import long_to_bytes

m, is_ok = gmpy2.iroot(c, e)
assert is_ok
flag = long_to_bytes(m)
print(flag)
```

## / Appendix

ちなみに51文字まではセーフなのですが、52文字になると$`m^5 > n`$になってしまいます。

たった1文字超えただけなので、「 $`\sqrt[5]{c + kn}`$ が整数になる $`k`$ を見つければいいじゃん」と思うかも知れません。しかし $`0 \le m < 2^{416}`$ と $`2^{2047} \le n < 2^{2048}`$ を用いると、暗号文の

$$0 < m^5 - kn < n$$

という関係から、$`k`$ は

$$0 < k < 2^{33}$$

の範囲にあることが分かります。1文字多いだけで $`2^{33}`$ 個の総当りをしなければならないことになり、なかなかしんどいです。

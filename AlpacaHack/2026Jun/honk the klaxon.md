# honk the klaxon

## / Overview

ランダムな32バイト(`CHALLENGE`)に対して、`bxor`と`pbox`という変換が32ラウンド行われます。これらは全てXOR演算のみで構成されており、線形変換として記述することができます。ここで、32バイトの入力値（`CHALLENGE`や`pt`）を32次元の列ベクトル $`c, p \in (\mathbb{F}_{2^8})^{32}`$ と見立てます。

```python
def encrypt(pt, key):
    for _ in range(ROUNDS):
        pt = bxor(pt, key)
        pt = pbox(pt)
    return pt
```

* **bxor**: `CHALLENGE`と同様に生成された32バイトの`KEY`（変数 $`k`$）と、入力 `pt`（変数 $`p`$）をXORします。つまり $`p \oplus k`$ です。
* **pbox**: `PBOX`のリストを用いて、特定のインデックスのバイト群をXORして新しいバイトを作ります。これは成分が $`\{0, 1\}`$ の $`32 \times 32`$ 正方行列 $`A`$ を用いて $`Ap`$ を計算していることと同値です。

1ラウンドの操作は $`p \leftarrow A(p \oplus k)`$ と表せます。
これを32ラウンド分展開すると、暗号化関数 $`f(p)`$ は次のように表されます。

$$f(p) = A^{32}p \oplus \bigg(\sum_{i=1}^{32}A^i\bigg)k$$

このチャレンジでは、ターゲットとなる $`f(c)`$ （`CHALLENGE`の暗号文）が与えられた状態で、任意の32バイトを入力した結果 $`f(p)`$ を複数回得ることができます。

## / Writeup

まずはオラクルに対して、全て `\x00` で構成された32バイトのゼロベクトルを入力し、$`f(0)`$ を得ます。
$`f(p)`$ の式において $`p=0`$ を代入すると、以下の等式が成り立ちます。

$$f(0) = \bigg(\sum_{i=1}^{32}A^i\bigg)k$$

ここで、ターゲットの暗号文 $`f(c)`$ と $`f(0)`$ のXORを取ると、右辺第２項を削除することができます。

$$f(c) \oplus f(0) = A^{32}c$$

行列 $`A`$ について調べると、$\mathrm{GF}(2)$ 上において正則であり逆行列を持つであることがわかります。そのため、SageMathなどを用いて逆行列 $`A^{-32}`$ を計算することができます。これを用いて両辺に左から $`A^{-32}`$ を掛けることで、元の `CHALLENGE` である $`c`$ を復元できます。

$$c = A^{-32}(f(c) \oplus f(0))$$

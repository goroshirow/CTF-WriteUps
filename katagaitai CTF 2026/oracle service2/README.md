# oracle service2

## / Overview

RSAオラクル(e, N)なし

## / Writeup

[racle service1](../oracle%20service1/)の改良版です。今度は逆元を求めるために必要な`N`も与えられません。よってこの`N`を計算します。

具体的には2つの`N`の倍数から最大公約数を求めることで`N`を求めます。この`N`の倍数は、例えば`2`と`3`をサーバーで暗号化してもらい、その結果$`c_1, c_2`$と公開情報$`e=65537`$から計算できます。なぜなら

$c_1 = 2^e - k_1 N$
$c_2 = 3^e - k_2 N$

であり

$k_1 N = 2^e - c_1$
$k_2 N = 3^e - c_2$

だからです。この最大公約数を取ると

$\text{gcd}(k_1 N, k_2 N)=N$

となります。($`k_1, k_2`$が共通因数をもつ場合は素因数分解するか$`c_3`$を作ってもう一度gcdを計算してください)

あとは[racle service1](../oracle%20service1/)と同じです。

# oracle service1

## / Overview

準同型性を用いたRSA暗号の解読

## / Writeup

### 解法1

ゴールは `m = b"katagaitai-CTF"` を暗号化したものをゲットすることで、公開されている情報は法`N`だけです。

直接 `m` をオラクルに送信すると拒否されるので次のような工夫をします。

* $`2m`$をオラクルで暗号化して$`c = 2^em^e \pmod N`$を受け取る
* $`2`$をオラクルで暗号化して$`2^e \pmod N`$を受け取る
* $`2^ex \equiv 1 \pmod N`$となる様な$`x=2^{-e}\pmod N`$(逆元)を手元で計算する
* $`cx \equiv m \pmod N`$を計算できる

これをサーバに送信してフラグゲット

### 解法2

もしくは`e=65537`と配布されたコードに書いているので、サーバーに`N`だけ聞くと、手元で`m`を暗号化できる。

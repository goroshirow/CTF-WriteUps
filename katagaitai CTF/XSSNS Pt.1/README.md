# XSSNS Pt.1

## / Overview

/xss/postから自分のページをクロールしてもらう

## / Writeup

http://web.katagaitai-ctf.net/xss/

にアクセスして適当な名前とパスワードで`register`します。マイページのURL (例: http://web.katagaitai-ctf.net/xss/user/pqZW23xtdTVJ ) を控えていてください。

`Report Admin`からマイページのURL ( /xss/user/pqZW23xtdTVJ ) を指定して、マイページに戻ると訪れた人として、フラグが表示されます。
